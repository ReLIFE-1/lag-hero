## 📖 游戏介绍

《**卡顿英雄：时空故障**》是一款基于**网络延迟（Lag）**与**时空残影**概念打造的赛博朋克风动作冒险网页游戏。

在濒临崩溃的数字霓虹矩阵中，物理法则被数据丢包与高延迟撕裂。玩家需要化身为能操控延迟与残影的时空黑客，利用“回溯”、“卡顿斩”与“相位穿透”，穿梭于失控的防火墙、故障守卫与时空裂隙之中！

## ✨ 核心特色 (v2.0 Matrix Overdrive)

1. **时空延迟与残影机制 (`platformer` + `game-feel`)**：
   - **卡顿斩 (Lag Slash, `J / X`)**：挥出高频刀光斩碎无人机与落石、**完美弹反敌方弹幕**；在开启【主动卡死】期间连续出刀可**积蓄多道延迟次元斩**，松开空格瞬间引爆高额伤害！
   - **主动卡死 (Lag Switch, `长按 Space`)**：全场时间流速骤降至 10%，BGM 自动降调慢放，叠加光学眩晕与视频坏块滤镜。
   - **丢包回溯 (Packet Loss, `Shift / Q`)**：将自身坐标与状态撤回至 1.5 秒前，并挽回刚扣除的生命值。
   - **穿模滑铲 (Collision Glitch, `S / E`)**：进入 2.2s+ 故障穿模态，无伤穿越实心防火墙并磁吸隐藏 Bug 碎片。
2. **局内 Roguelike 故障协议构筑 (`roguelike` + `card-game`)**：
   - 每推进 300m 或击败守门人 Boss，触发**「内存溢出 · 协议三选一」**（如*量子丢包爆破、DDoS 脉冲新星、延迟剑气风暴、三段跃迁驱动、热修复圣盾*），支持可复现随机种子（Seeded RNG）。
3. **阶段性 Boss 战与三大主题扇区**：
   - 随距离推进动态切换 **霓虹缓存区 → 蓝屏死机深渊（低重力） → 内核熔毁炼狱**，迎战【404 守门人·防火墙巨像】与【死循环核心·木马母体】。
4. **RPG 局外黑市改装、多特工机体与悬赏成就馆 (`rpg` + `visual-novel`)**：
   - 收集的数据金币 (`🪙`) 与 Bug 碎片 (`💠`) 永久存档，可在主页**黑市改装车间**升级生命、带宽、刀锋、磁铁与开局护盾，解锁 **零号黑客 / 幽灵行者 / 时之剑客** 三大特工机体，并体验带分支增益的赛博终端通讯剧情。
5. **模块化多文件架构（零第三方依赖）**：
   - 拆分为清晰的 `css/` 与 `src/`（`config/`, `core/`, `audio/`, `systems/`, `entities/`, `render/`）多文件结构，同时完美兼容本地双击 `index.html` 与 GitHub Pages 静态部署。
