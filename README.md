## 📖 游戏介绍

《**卡顿英雄：时空故障**》是一款基于**网络延迟（Lag）**与**时空残影**概念打造的赛博朋克风动作冒险网页游戏。

在濒临崩溃的数字霓虹矩阵中，物理法则被数据丢包与高延迟撕裂。玩家需要化身为能操控延迟与残影的时空黑客，利用“回溯”、“卡顿斩”与“相位穿透”，穿梭于失控的防火墙、故障守卫与时空裂隙之中！

## ✨ 核心特色

1. **时空延迟与残影机制**：
   - **卡顿斩 (Lag Slash)**：定格时间并积蓄多道残影连斩，瞬息爆发强力伤害！
   - **时空回溯 (Rollback)**：将自身坐标与状态撤回至数秒前，规避致命陷阱与激光。
   - **相位漫步 (Phase Shift)**：短时间内进入非实体状态，无伤穿越防火墙与敌人群体。
2. **沉浸式赛博朋克视听**：
   - 动态 CRT 扫描线、时空故障抖动与眩晕滤镜。
   - 基于原生 Web Audio API 合成的电子低音与赛博节拍音效，完全自包含。
3. **零依赖单文件设计**：
   - 纯前端原生 HTML5 + Canvas + Web Audio API 编写，无第三方库依赖，加载速度毫秒级。
